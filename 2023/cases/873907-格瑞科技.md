# 南阳格瑞光电科技股份有限公司（873907·新三板/历史通道）审核问询法律问题回溯

> 上市/挂牌日期：2023-01-31；问询轮次：第一次反馈意见，共1轮。依据文件：`20221227_南阳格瑞光电科技股份有限公司反馈意见回复.txt`（2022-12-27）；另核对 `20221108_南阳格瑞光电科技股份有限公司法律意见书.txt`（2022-11-08）。中介机构：主办券商为山西证券股份有限公司；发行人律师为河南驰誉律师事务所；会计师为中兴财光华会计师事务所（特殊普通合伙）。本报告仅覆盖历史通道挂牌审核期间问询。

## 一、公司与审核概况

格瑞科技主营智慧城市解决方案、精密光学元件及智能杆件设备业务，智慧城市客户以政府机关为主，业务在河南省集中开展。本轮反馈共13项，除收入、盈利能力、客户集中度、应收账款、偿债能力、合同履约成本、政府补助和所得税等财务业务问题外，法律核查集中于智慧城市项目资质、政府项目涉密信息系统集成边界、全资子公司合法规范经营、前次新三板挂牌及摘牌后的新增股东、外协采购的资质和依赖风险。回复披露公司持有城市及道路照明工程专业承包三级资质，配置2名全职注册建造师；唐河县委机要保密局于2022-11-25出具《证明》确认政府项目不属于涉密信息系统集成；公司曾于2015-04-30以832384挂牌、2019-02-20终止挂牌，现申请历史通道挂牌。

## 三、重点法律问题详述

### 1.1 问题2：智慧城市项目资质、注册建造师及涉密业务边界

**来源定位：** `20221227_南阳格瑞光电科技股份有限公司反馈意见回复.txt`第909—1,075行，PDF第21—25页。

**问询要点（完整子问题）：**

1. 说明智慧城市业务涉及施工的具体环节，并核查公司是否具备生产经营所必需的资质、备案。
2. 核查城市及道路照明工程专业承包三级资质是否要求全职注册建造师；如要求，说明注册建造师是否全职任职及是否存在资质挂靠。
3. 核查公司为政府机关提供服务是否需要取得涉密信息系统集成资质。

**回复与核查要点（逐项对应）：**

- 对施工内容和资质清单：后端施工包括硬件精细化安装、软件平台搭建、数据库部署及软硬件一体化调试；前端施工包括综合布线、基础开挖、立杆安装。公司持有城市及道路照明工程专业承包三级资质`D341331769`，由南阳市住房和城乡建设局于2021-05-20颁发，有效至2026-05-20；另持高新技术企业证书`GR202141000213`、安全生产许可证`豫JZ安许证字{2021}131540`、报关单位注册登记证书`4116950566`和对外贸易经营者备案登记表`04713060`，回复据此认为经营资质和备案齐备。
- 对注册建造师和挂靠：主办券商查阅员工名册、社保凭证、劳动合同、注册执业证书、学历资料，并检索全国建筑市场监管公共服务平台；依据回复引用的《中华人民共和国建筑法》《建筑业企业资质标准》，城市及道路照明工程专业承包三级资质要求市政公用工程、机电工程专业注册建造师合计不少于2人。公司现有2名注册建造师全职任职，取得`D341331769`的资质承接项目，回复称不存在借证、挂靠或人员与资质分离。
- 对涉密信息系统集成：回复引用《涉密信息系统集成资质管理办法》，区分涉密系统规划、设计、建设、监理、运行维护与一般政府信息化项目；中共唐河县委机要保密局于2022-11-25出具《证明》，确认公司自2020-01-01以来为政府机关提供的服务不属于涉密信息系统集成，未受到保密行政处罚。主办券商同时查阅政府采购文件和主要合同，未发现委托单位要求供应商取得涉密资质，因而认为无需取得该项资质。

**核查程序：** 查阅公司主要业务合同、营业执照、`D341331769`资质证书、`豫JZ安许证字{2021}131540`安全生产许可证、人员劳动合同和社保缴纳凭证；检索住建部全国建筑市场监管公共服务平台；查阅政府采购文件、主要项目合同及唐河县委机要保密局2022-11-25《证明》。

**核查意见：** 回复载明主办券商及律师认为公司已取得智慧城市、照明施工、软件技术服务及安全生产所需的资质和备案，2名注册建造师为全职人员且不存在资质挂靠；政府项目不属于涉密信息系统集成，未发现因资质不足受到处罚。律师意见的完整签章及具体论证仍以法律意见书原件为准。

**执业提示：** 政府项目合规审查应按“项目内容—施工环节—合同要求—法定资质—人员注册状态”逐项匹配；《证明》只解决已开展项目的涉密属性，不能自动覆盖未来涉及涉密数据、涉密系统或新增施工范围的项目。

### 1.2 问题3：全资子公司设立、业务变动及合法规范经营

**来源定位：** `20221227_南阳格瑞光电科技股份有限公司反馈意见回复.txt`第1,076—1,240行、PDF第25—28页，并结合第185—187页子公司核查段落。

**问询要点（完整子问题）：**

1. 说明南阳格瑞科技有限公司的设立背景、股权结构、主营业务、治理安排及与母公司的业务关系。
2. 说明子公司报告期资产、负债、收入、利润及业务结构变化，是否存在重大资产重组或利益输送。
3. 说明子公司董事、监事、高级管理人员、财务、人员和经营场所是否独立，是否存在关联交易或资金占用。
4. 核查子公司报告期合法规范经营、税务、环保、安全、劳动、公积金及行政处罚情况。

**回复与核查要点（逐项对应）：**

- 对设立和治理：南阳格瑞科技有限公司为公司全资子公司，主要承担精密光学元件业务；回复披露其无董事会，由执行董事肖鹏飞负责、曹江涛担任监事，未发现被列为失信被执行人或受到重大行政处罚。母公司继续经营智慧城市和智能杆件业务，子公司负责光学元件，两个业务条线通过监控设备和光电产业链形成协同。
- 对财务和业务变化：截至2022-07-31子公司资产53,479,762.86元、负债42,760,306.59元、净资产10,719,456.27元；2021年资产53,806,635.02元、负债41,313,026.75元、净资产12,493,608.27元；2020年资产60,325,625.38元、负债52,864,008.07元、净资产7,461,617.31元。收入分别为2022年1—7月5,040,080.73元、2021年21,325,100.38元、2020年39,384,705.08元，2022年光学业务占99.97%，未披露重大资产重组。
- 对人员、资产和关联关系：回复按母子公司银行账户、固定资产、人员、技术和业务合同进行核对，称子公司独立核算、独立用工和独立开展光学元件业务，未发现母公司或实际控制人通过子公司进行资金占用或利益输送；南阳格瑞科技有限公司无独立董事会并不当然否定其法人治理，仍需以执行董事决定、监事履职和母公司授权文件核验。
- 对合法规范经营：主办券商取得子公司信用报告、营业执照、业务资质及主管部门证明，查询市场监管、税务、劳动、公积金、安全、环境、执行和失信信息；回复称未发现报告期内刑事处罚、重大行政处罚、环保安全处罚、欠薪或社保公积金处罚，子公司经营合法规范。TXT未逐项列出所有证明文号，未载明的具体证明编号应以原件补核。

**核查程序：** 查阅子公司工商档案、营业执照、章程、执行董事及监事文件、审计报告和财务报表；核对2020—2022年资产、负债、收入、净利润、银行账户、固定资产和人员清单；取得市场监管、税务、环保、应急、人社、公积金等主管部门证明并进行公开网站查询。

**核查意见：** 回复载明主办券商及律师认为，南阳格瑞科技有限公司为公司全资控制、业务定位明确、报告期内合法规范经营，未发现重大违法、关联资金占用或持续经营障碍。因部分公司及子公司已于2022年8—10月注销，具体注销登记日期和法律意见书签章页应补核。

**执业提示：** 子公司合法合规核查不能仅引用母公司对外承诺，应形成营业执照、实际经营、税务环保安全、人社公积金和银行账户的闭环；业务收入由母公司转向子公司时，还要核对客户合同主体和知识产权使用权。

### 1.3 问题4：前次挂牌、摘牌后股权变动及新增股东

**来源定位：** `20221227_南阳格瑞光电科技股份有限公司反馈意见回复.txt`第1,241—1,678行、PDF第28—37页。

**问询要点（完整子问题）：**

1. 说明本次申请挂牌与前次挂牌期间在信息披露、股权结构、主营业务、子公司、关联方和风险披露方面的差异及原因。
2. 说明公司前次挂牌期间及摘牌后至本次申报期间是否合法合规、是否违反公开承诺、公司及相关人员是否受到处罚，是否构成本次挂牌障碍。
3. 说明摘牌后至本次申报期间新增重要股东的身份、持股及相关信息披露是否完整。

**回复与核查要点（逐项对应）：**

- 对两次挂牌期间和披露差异：公司曾于2015-04-30在全国股转系统挂牌，证券简称格瑞光电、证券代码832384，并于2019-02-20终止挂牌；前次报告期为2012年度、2013年度和2014年1—10月，本次报告期为2020年度、2021年度和2022年1—7月，两个报告期没有重叠。回复称差异来自摘牌后股权转让、员工持股、监事和高管变动、经营范围和子公司变化，不属于重大信息矛盾。
- 对前次挂牌合规和承诺：主办券商检索中国证监会证券期货市场失信记录、全国股转系统、中国裁判文书网、国家企业信用信息公示系统和执行信息公开网，并取得工商、税务证明；回复称公司及主要股东、董监高未受到刑事处罚、证监会行政处罚、行政监管措施、全国股转公司纪律处分或自律监管措施，未违反《关于避免同业竞争的承诺》《关于避免及减少关联交易的承诺函》等公开承诺。
- 对新增股东：截至2022年10月公司股本31,677,099股，由肖鹏飞、肖向、王淼、贾长勤等28名自然人股东和昱丰咨询1名机构股东持有；摘牌后至本次申报新增6名自然人股东和1名机构股东，主办券商查阅工商档案、股东名册、股权转让合同、三会文件、营业执照和身份证明，回复认为新增股东身份及持股信息已在《公开转让说明书》“股东适格性核查”中完整披露。

**核查程序：** 比对前次挂牌申请文件、挂牌期间公告、本次申请文件及信息披露制度；查阅摘牌后的股东名册、工商档案、股权变动合同、三会文件、机构营业执照和自然人身份证明；查询处罚、失信、执行及裁判信息，逐项核对公开承诺履行情况。

**核查意见：** 回复载明主办券商及律师认为，前次挂牌与本次申报报告期不重叠，披露差异具有时间和经营变化原因；公司及相关人员未发现重大违法或违反公开承诺，摘牌后新增6名自然人及1名机构股东的信息披露完整。对每一名新增股东的取得价格、资金来源和是否属于突击入股，回复未逐一展开，需结合股权转让原件继续核验。

### 1.4 问题5：外协采购、施工资质及持续经营依赖

**来源定位：** `20221227_南阳格瑞光电科技股份有限公司反馈意见回复.txt`第1,679—1,756行、PDF第37—39页。

**问询要点（完整子问题）：**

1. 说明外协服务的具体质量控制措施。
2. 说明外协在公司整个业务中的环节和所占地位。
3. 核查外协服务商与公司股东、董事、监事、高级管理人员及其他关联方是否存在关联关系。
4. 核查外协服务商是否需要取得施工等资质，资质是否齐备。
5. 核查公司是否对外协服务商存在依赖，外协环节是否对持续经营能力构成重大影响。

**回复与核查要点（逐项对应）：**

- 对质量控制：报告期外协主要为镀锌，零星为焊接和喷塑；公司通过供应商定期审核、外协产品质量评价、改进计划、完工检验和《采购管理制度》《供方管理控制程序》控制质量。主办券商抽查外协协议、采购台账、验收资料和质量记录，回复称未发生因外协质量导致行政处罚、客户索赔或重大经营事故。
- 对业务环节和金额：智能杆件生产流程为下料、切割、折弯、焊接、镀锌、喷塑，镀锌位于中间工序，主要作用是提高防腐性能；外协加工费占智能杆件业务成本比例为2021年2.72%、2022年1—7月1.52%，占比低且市场可替代厂商较多，回复据此认为外协不构成核心业务依赖。
- 对关联关系：主要外协厂商为邓州市和信机械设备有限公司、河南中联交通产业发展有限公司、湖北华联热浸锌有限公司、新野县天大金具加工有限责任公司、唐河县强盛电子设备安装工程有限公司、新野县大明灯具厂；主办券商查询国家企业信用信息公示系统的股东及董监高，访谈公司和供应商并取得承诺，回复未发现与公司股东、董监高或其他关联方存在关联关系。
- 对资质：前四家提供热浸锌加工，唐河县强盛电子设备安装工程有限公司提供灯箱焊接，新野县大明灯具厂提供灯杆喷塑；回复认为上述是加工劳务，不属于必须取得施工资质的建设施工。2021年初喷塑因公司生产线尚未调试完成而临时外协，2022年初焊接因订单较多而临时外协，后续分别由自有生产线、增加人员和提升技能替代。
- 对依赖及核查结论：公司取得外协加工明细账、成本占比、替代供应商和设备情况，核对外协厂商经营范围和实际服务；回复认为外协厂商数量较多、市场竞争充分、工序非核心且可替代，不影响持续经营能力。律师及主办券商结论限于外协成本、合同、质量和供应商公开信息，不能覆盖未提供的口头加工安排。

**核查程序：** 查询六家外协厂商工商登记、股东、董监高、经营范围和信用记录；查阅外协协议、采购明细账、质量验收、供应商审核和替代供应商资料；核对2021年2.72%、2022年1—7月1.52%的成本占比，并访谈生产、质量及采购人员。

**核查意见：** 回复载明主办券商及律师认为外协供应商与公司及关联方无关联，所提供加工不需要施工资质，质量控制和替代性足以支持公司持续经营，未发现重大依赖或利益输送。

**执业提示：** “外协加工不需要施工资质”的结论必须根据工序和合同责任边界判断；如果供应商实际承担现场安装、工程施工或项目质量责任，应重新核对资质、保险和安全生产义务，不能直接套用本轮回复结论。
