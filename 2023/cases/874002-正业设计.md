# 正业设计股份有限公司（874002·新三板/历史通道）审核问询法律问题回溯

> 上市/挂牌日期：2023-02-07；问询轮次：第一次反馈意见，共1轮。依据文件：`20230110_正业设计股份有限公司反馈意见回复.txt`（2023-01-10）；另核对 `20221128_正业设计股份有限公司法律意见书.txt`（2022-11-28）。中介机构：主办券商为民生证券股份有限公司；发行人律师为湖南启元律师事务所；会计师为立信会计师事务所（特殊普通合伙）。本报告仅覆盖历史通道挂牌审核期间问询。

## 一、公司与审核概况

正业设计主要提供以农业、水利工程为主，市政、建筑为辅的全过程工程咨询管理服务，覆盖项目建议书、可行性研究、工程勘察、工程设计、工程造价和工程监理。本轮反馈共8项，法律问题集中于外协及外包采购、原子公司黑龙江和信勘测设计有限公司转出后继续交易、前员工配偶控制的哈尔滨农垦恒义勘测设计有限公司交易、合作研发成果和知识产权、业务资质及人员挂靠、全资子公司管理控制、关联交易和公司治理。回复披露公司外协主要为测量、钻探、地质物探、辅助设计和专家咨询，恒义勘测2022年1—6月、2021年、2020年采购金额分别为54.72万元、110.38万元、314.25万元；截至2022-12-15，公司具有注册类和职称类资质员工215人，占总人数327人的65.75%，未发现资质挂靠。

## 三、重点法律问题详述

### 1.1 问题1：外协外包采购、恒义勘测交易及供应商责任

**来源定位：** `20230110_正业设计股份有限公司反馈意见回复.txt`第76—964行、PDF第4—24页。

**问询要点（完整子问题）：**

1. 补充说明外协外包采购具体内容、是否与主营业务相似，以及各类外协成果的呈现和使用方式。
2. 说明转出原子公司黑龙江和信勘测设计有限公司的背景、原因及外协服务商与公司股东、董事、监事、高级管理人员的关联关系。
3. 结合向哈尔滨农垦恒义勘测设计有限公司采购的具体内容，说明价格是否公允、是否存在利益输送，并核实前五大供应商表中“无关联关系”的披露。
4. 说明外协外包必要性、供应商工作内容、公司独立完成环节、外协在业务中的地位、是否涉及核心业务或关键技术，并说明供应商人员配置及服务人员数量是否匹配。
5. 说明供应商是否需要并具备相关资质，外协外包是否合法合规。
6. 说明合同权利义务、责任划分、质量控制、纠纷、客户知悉及合同约定、对经营成果和业务质量稳定性的影响。
7. 说明供应商选择标准和流程、是否存在特定供应商、关联关系、定价机制、利益输送或供应商承担公司成本，并说明供应商能否越过公司直接接触客户。

**回复与核查要点（逐项对应）：**

- 对采购内容和成果：公司主营全过程工程咨询，外采主要为地形测绘与测量、地质勘察与物探、现场数据收集，少量辅助设计、钻探和专家咨询。外业钻探形成样品、地质编录，测量形成河道、堤防、道路和地形测量报告，设计形成电子规划图、施工图，咨询形成专家意见；公司勘察负责人、设计人员和项目负责人对成果进行化验、修改、完善并向客户提交最终成果，回复称未将核心业务整体外采。
- 对和信勘测：黑龙江和信勘测设计有限公司原为公司子公司，2015-11-12转出；回复披露其前身黑龙江农垦宏盛农业开发有限公司于2011-03-24设立、注册资本50.00万元，2015-11-30评估基准日净资产评估值111,523.86元，后更名为和信勘测。主办券商及律师查阅工商档案、转让文件和供应商资料，未发现转出安排造成公司控制权、知识产权或客户资源回流。
- 对恒义勘测和价格：恒义勘测由梁丽100%持有，梁丽的配偶柴雅俊曾在公司任职；公司向其采购测量服务，金额为2022年1—6月54.72万元、2021年110.38万元、2020年测量248.68万元加设计65.57万元合计314.25万元。价格依据《测绘生产成本费用定额》（财建[2009]17号）及黑龙江市场价格，GPS E点测量4,100元/点，堤防条带测量22,000元或11,000元/平方公里，地形测量42,000元、24,000元、12,500元或5,800元/平方公里；回复称与其他供应商无重大价差，不存在利益输送，前五大供应商“无关联关系”表述已按前员工配偶关系补充核实。
- 对必要性、人员和核心环节：工程咨询项目存在业主压缩工期和内部产能错配，外协可补充测量、钻探、数据收集和非核心设计；公司总人数2020年327人、2021年274人、2022年1—6月268人，供应商根据项目配置外业人员，回复称人员数量与服务能力相匹配。项目方案、核心技术路线、成果审查、客户沟通和最终交付由公司完成，外协不涉及公司核心业务控制权。
- 对资质和合法性：公司及供应商按《建设工程勘察设计资质管理规定》《工程设计资质标准》区分公司承接的勘察设计资质与外业钻探、测量等辅助劳务；回复认为外协服务不构成公司超资质经营，钻探劳务不替代公司设计资质。主办券商和律师查阅供应商营业执照、业务合同、项目成果和公司资质，未发现供应商以挂靠方式承接公司项目。
- 对合同责任、质量和客户：公司制定《外委项目流程说明及管理办法》《外委项目质量控制管理办法》，通过两家以上供应商询价、项目负责人审核、合同约定、成果验证和年度评价控制质量；公司原因导致返工由公司承担，供应商原因导致返工由供应商无偿返工。回复称客户一般知悉公司为完成项目采购辅助服务，公司仍对最终成果和客户责任负责，未发现质量纠纷或潜在争议。
- 对选择、定价和越过公司：公司根据项目资质、技术能力、履约记录、价格和工期选择供应商，执行询价、审批、合同和验收流程；回复称不存在特定供应商专门提供服务，不存在供应商为公司承担成本、费用或向客户直接收款的情形。供应商只接触其负责的基础资料，最终方案和客户合同由公司控制，未发现供应商绕过公司直接承接公司客户。

**核查程序：** 查阅和信勘测转出工商资料、恒义勘测股东及董监高信息、采购合同、测量成果、结算单、发票和银行付款；将4,100元/点、22,000元/平方公里等价格与市场及其他供应商报价比较；查阅《外委项目流程说明及管理办法》《外委项目质量控制管理办法》、项目验收和客户沟通记录；访谈公司项目负责人、供应商及柴雅俊，并检索关联关系和诉讼处罚。

**核查意见：** 回复载明主办券商及律师认为，外协外包属于行业常见的辅助性采购，恒义勘测交易价格公允，未发现利益输送、资质挂靠、重大依赖、质量争议或供应商越过公司获客的情形；与前员工配偶的关系应以实质关联关系口径披露，不能仅以其非公司股东为由写成“无关联”。

**执业提示：** 工程咨询外协审查必须区分“基础资料采集、辅助设计、核心方案设计、最终成果签发”四个环节；前员工配偶供应商应按关联关系、交易价格和利益输送三条线同步核查，且公司应保存客户对外协安排的知悉或合同允许证据。

### 1.2 问题2：合作研发、成果归属及核心技术贡献

**来源定位：** `20230110_正业设计股份有限公司反馈意见回复.txt`第965—1,171行、PDF第24—29页。

**问询要点（完整子问题）：**

1. 说明与河海大学、京水江河、华南研究所合作研发的权利义务、工作成果、专利、使用权、成本支付、成果归属及纠纷情况。
2. 说明合作研发形成的主要技术、专利及其对公司收入的贡献，核查是否存在技术依赖或权属不清。

**回复与核查要点（逐项对应）：**

- 对河海大学项目：公司与河海大学于2019年10月至2020年12月开展《技术开发合同书》项下合作，已形成项目成果报告，公司支付合作费用22.07万元且全部计入项目成本；回复称合作成果由双方按合同约定共有，但由公司实施并取得业务收入，未披露专利权属争议或第三方主张。
- 对京水江河项目：公司于2020年9月与京水江河开展合作，回复出具时项目仍在进行，尚未形成最终成果、未支付合作费用；主办券商及律师核查合作合同和项目进展，TXT未载明项目专利号或结项日期，故该项成果归属和后续支付仍需以合同及结项文件补核。
- 对华南研究所项目：公司于2020年12月与华南研究所签署《技术开发合同书》，项目尚未完成，公司已支付40.00万元；回复称新技术成果由公司享有，现阶段未披露专利登记号和成果验收时间，不能仅以已付款推导成果已完成或权属已经登记。
- 对收入和技术：合作研发及自主研发成果服务于农业、水利工程咨询；公司主要技术收入2022年1—6月72,105,133.05元、占总收入75,818,673.86元的95.10%，2021年158,448,651.78元、占169,005,692.96元的93.75%，2020年155,776,198.60元、占161,455,808.92元的96.48%。回复列示`ZL201820854400.2`、`ZL201920175080.2`、`ZL201820855849.0`等专利，称合作研发未形成对单一合作方的重大技术依赖。

**核查程序：** 查阅三份《技术开发合同书》、项目立项、成果报告、付款凭证、专利证书及收入明细；访谈项目负责人和合作方，核对公司使用成果的业务项目、专利申请主体、共有权利安排和报告期收入比例。

**核查意见：** 回复载明主办券商及律师认为合作研发合同真实，费用支付和成果使用具有业务背景，未发现权属争议或重大技术依赖；京水江河、华南研究所项目尚未完成或权属细节未在TXT充分载明，相关结项、专利和后续付款资料属于待补底稿。

**执业提示：** 合作研发合同应逐项明确专利申请权、著作权、技术秘密、成果交付和客户使用许可；对共有成果不能只写“公司可实施”，应保留共有人同意、许可范围和收入对应项目的证据。

### 1.3 问题3：业务资质、专业人员和挂靠风险

**来源定位：** `20230110_正业设计股份有限公司反馈意见回复.txt`第1,172—1,722行、PDF第29—40页。

**问询要点（完整子问题）：**

1. 说明公司开展各类工程咨询、勘察、设计业务所需资质、资质有效期及是否存在使用过期资质或超范围承接业务。
2. 说明公司专业技术人员数量、结构和流动情况，是否满足资质持续条件。
3. 说明相关法律政策是否会影响资质延续和业务承接，是否存在重大持续经营风险。
4. 核查第三方挂靠承接项目、出借资质或专业技术人员挂靠取得资质的情形。

**回复与核查要点（逐项对应）：**

- 对资质和有效期：公司持有工程设计、工程勘察、测绘、监理等业务资质，`B123004508`、`A123004508`有效期至2023-12-31，`A223004505`有效期至2024-11-26，监理资质`E123004508`亦列入现有资质；回复称 pending renewal 的咨询和水利资质不影响报告期内既有业务，未发现超资质或使用过期资质承接项目。
- 对人员数量和结构：截至2022-12-15，公司共有注册类和职称类资质员工215人，占327名员工的65.75%，主要为农业、水利勘察设计技术人员；2022年1—6月入职67人、入职率22.30%、离职14人、离职率4.66%，2021年入职45人、离职39人，2020年入职68人、离职78人，回复称流动率符合行业特点。
- 对延续风险：主办券商及律师查阅《建设工程勘察设计资质管理规定》《工程设计资质标准》、住房和城乡建设部及自然资源主管部门网站，结合项目合同、收入和人员结构判断资质条件；回复认为公司规模、技术和人员满足现有资质要求，不能持续拥有资质的风险较小，不会对未来承接农业水利工程产生重大不利影响。
- 对挂靠：公司取得资质人员均与公司签署劳动合同、由公司缴纳社保并发放工资；主办券商核对员工名册、合同、社保、工资、项目合同、招投标文件和主要供应商，查询住建、自然资源、信用中国等网站，回复称不存在第三方通过公司挂靠承接项目、公司出借资质或专业技术人员挂靠取得资质的情形。

**核查程序：** 逐项核对资质证书、有效期、主要项目合同和中标文件；取得215名资质人员劳动合同、社保缴费、工资资料；查阅员工入离职台账、业务收入和项目成果，检索住建部全国建筑市场监管公共服务平台、自然资源主管部门及信用中国。

**核查意见：** 回复载明主办券商及律师认为公司已取得必要资质，不存在超范围、过期使用或挂靠，人员结构与主营业务匹配，资质延续风险较小。`B123004508`、`A123004508`的后续续期状态不在本次TXT事实范围内，应另行核验。

**执业提示：** 资质合规意见应以承接项目的实际工作内容、证书有效期和人员社保工资为基础；工程设计企业的注册人员变动较快，挂牌后应建立证书到期、人员离职和项目承接的动态清单。

### 1.4 问题4：全资子公司业务定位、内部交易及独立管理

**来源定位：** `20230110_正业设计股份有限公司反馈意见回复.txt`第1,723—1,921行、PDF第40—45页。

**问询要点（完整子问题）：**

1. 补充披露佳永科技、好排科技、长宏勘察与公司的业务衔接、流程环节、分工合作、市场定位和未来发展，说明对子公司是否依赖及对持续经营能力的影响。
2. 披露子公司主要客户、母子公司内部交易及内部交易最终实现情况。
3. 结合股权、决策机制、公司制度和利润分配说明公司如何在人员、财务、业务方面管理和控制子公司。

**回复与核查要点（逐项对应）：**
