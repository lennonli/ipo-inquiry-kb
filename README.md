# IPO与挂牌审核问询法律问题案例库

A股 IPO（北交所/科创板/创业板/沪深主板）及新三板挂牌项目**审核问询中法律问题的回溯分析库**。一司一文，基于审核期间公开披露的问询回复、法律意见书提炼，重点沉淀"问询要点—回复与核查要点—执业提示"，供办理同类项目时检索论证范本与证据链构建思路。

> 内容均来自公开披露文件；`执业提示` 为个人业务心得。**私有仓库，请勿外传。**

## 快速使用

```bash
# 本地检索（任何 AI / 终端均可）
grep -l "股权代持" cases/*.md          # 按标签/关键词找案例
python3 scripts/build-index.py          # 重建索引 scripts/index.json
python3 -c "import json;[print(x['file'],x['tags'])for x in json.load(open('scripts/index.json'))if'股权代持'in x['tags']]"
```

- **远程/手机**：网站 `https://ai.licheng.uk/kb/`（列表筛选 + 全文搜索，浏览器即用）
- **AI 智能体**：本仓库为纯 Markdown，ZCode / Claude Code / Codex 本地 clone 后直接检索；配套 skill `ipo-kb`（见 `~/.agents/skills/`）

## 目录结构

```
cases/           案例正文，一司一文，文件名"代码-简称.md"（无代码的在审项目仅"简称.md"）
templates/       case-template.md 新案例模板
scripts/
  index.json     全库索引（build-index.py 生成，勿手改）
  build-index.py 从 frontmatter 重建索引
  migrate_20260825.py  首次存量迁移脚本（242份，已归档，仅留档）
```

## frontmatter 字段规范

| 字段 | 说明 |
| --- | --- |
| company / short | 公司全称（与正文 H1 一致）/ 简称（与文件名一致） |
| code | 证券代码（加引号防误判数字）；在审未上市留空 |
| board | 北交所 / 科创板 / 深市创业板 / 沪市主板 / 深市主板 / 新三板 |
| layer | 仅新三板填：基础层 / 创新层 |
| listing_date | 上市/挂牌日期；原文"【待核验】"的留空 |
| inquiry_rounds | 问询轮次（不含落实函） |
| cutoff_date | 文档资料截止日期 |
| lawyer | 发行人/申请人律师律所全称；**原文未载明的留空，不得推测**（现存 15 份空值系原文以"签章页为准"等方式未载明） |
| tags | 归一化法律类别标签，从"法律问题总览"表提取 |

## 新增案例流程

1. 复制 `templates/case-template.md` 到 `cases/代码-简称.md`，按模板填写；
2. 运行 `python3 scripts/build-index.py`；
3. `git add . && git commit -m "新增 XX 案例" && git push`——网站自动更新。
