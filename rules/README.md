## 元数据与索引

- 每篇 md 的 frontmatter 注明 `title` / `authority`（发布机关）/ `publish_date` / `category` / `subcategory` / `source_url`（原网页链接）。约定 `category` = 目录名去数字前缀（如目录 `10-并购重组` ↔ category `并购重组`）。
- 已知字段缺口：`authority` 缺失 243 部（约 19%）、`subcategory` 缺失 210 部（约 16%），检索时该两维度覆盖不全。
- 全文检索与元数据索引：`scripts/index.json`（1,286 条，与 md 一一对应）。检索：`kb_search.py search --kb rules`。
- 命名说明：个别法规名超长（超 macOS 255 字节文件名限制），文件名为截断名+8位哈希，法规全称以 frontmatter `title` 为准。
- `attachments/`：3 个非 md 原件（1 doc、2 pdf），各被一篇同名 md 以文本方式引用。
